# Example Data

`polyhaven_lvsm_test/` is the expected location of the downloadable LumiTokens
quickstart dataset. The dataset itself is ignored by Git and will be distributed
as a separate archive.

During local release development, this path may be a symlink to the internal
staging copy. Public users should extract the downloaded archive so that the
following file exists:

```text
examples/polyhaven_lvsm_test/full_list.txt
```

The main README will provide the archive URL, checksum, size, and extraction
command after the dataset has been packaged and approved for redistribution.
